front page — Trump vowing a 10% cap on credit card rates, Mexico capturing
cartel boss El Chapo Isidro, a boat capsizing in Nigeria killing 24, NATO
vowing to defend every inch of Poland, COP31 climate talks running into
overtime, and a 6.7-magnitude quake hitting Peru.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` checks the held `entry.png` (whole PNG, within the 1 MiB and
1024-pixel limits) and copies it to the output directory.
